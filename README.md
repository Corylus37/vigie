# Vigie

Site de présentation de Vigie, un robot de suivi de tendance sur BTC, ETH et SOL :
une décision par jour, règle publique, résultats de tests et défauts assumés.

- `index.html` : le site (une seule page, sans dépendance à installer).
- `journal.csv` : journal du test sur papier, publié automatiquement chaque nuit par le serveur de Vigie.
  Le site le lit à chaque visite.

Les chiffres affichés proviennent de simulations sur données passées et d'un test en argent fictif.
Ils ne constituent ni un conseil en investissement ni une promesse de résultat.
